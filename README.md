# AI x Epistemics Research Sprint 2026: Track 1 project

Code and data for our Track 1 ("Model Epistemics & Decision-Making Evals") submission to the Apart Research
AI x Epistemics Research Sprint, 13 to 15 November 2026.

## What was done when

All code and data in this repository were created during the sprint, starting 13 November 2026. There is no
pre-existing code. The official report template in `reference/` is Apart's.

## Layout

- `infra/`: setup for the GPU box (vLLM serving Qwen/Qwen3.6-35B-A3B) and an idle watchdog that stops the box.
- `reference/`: the official report template.

More folders (harness, analysis, results) will be added as the sprint goes on.
